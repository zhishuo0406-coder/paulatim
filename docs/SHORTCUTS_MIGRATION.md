## 已确认与尚未接收

已检查 `WorkLogSync/WorkLogSync.cs` 的 `Row`、`Parse`、`IsHeader`、`Period`，以及 `WorkLogDispatch.cs` 的 `Snapshot`、`BuildMail`、周期与回执逻辑。已检查配置模板和虚构示例。

当前输入契约为 `timestamp,task,actual_minutes,effective_minutes`。Task已经存在，旧「事项」对应它；新增的是独立Category和更通用的手机输入流程。用户说明旧流程以IELTS为主，但没有收到实际 `.shortcut` 导出、编辑器步骤或真实CSV；没有验证手机现有变量和写文件动作的具体配置。下面是按代码契约设计的修改清单，而非声称已经检查过手机快捷指令。

解析器按位置读取，逐行要求恰好四列，不按列名自动映射。仅识别首行的固定四列表头。生成的JSON为schema_version=2，行内有timestamp、task、actual_minutes、effective_minutes、record_number，没有category。统计的by_task按事项文本分组；邮件也只显示事项和两种分钟。

同步保留原始CSV字节，邮件控制器核对来源、镜像、状态和附件散列。因此仅修改手机输出为五列会导致校验失败，后续发信停在waiting_source；保留旧副本并不代表还能把它作为最新数据发送。

## 最小推荐格式

保留现有四列的位置，把category追加为第五列。手机提问顺序可以是Category、Task、Actual Time、Effective Time，不要求与存储顺序相同。

| 列 | 字段 | 规则 |
| --- | --- | --- |
| 1 | timestamp | 保留现有北京时间格式，分钟或秒精度 |
| 2 | task | 具体事项的非空文本，原Task不重命名或重写 |
| 3 | actual_minutes | Actual Time，非负分钟数 |
| 4 | effective_minutes | Effective Time，非负分钟数 |
| 5 | category | IELTS、Projects、Academic、Career之一 |

以下全部是虚构示例，仅用于说明未来格式，当前程序不能读取五列：

```csv
timestamp,task,actual_minutes,effective_minutes,category
2030-01-01 09:00,"Listening, practice",30,20,IELTS
2030-01-01 10:00,Prototype documentation,45,35,Projects
2030-01-01 11:00,Example paper notes,40,30,Academic
2030-01-01 14:00,Example interview practice,25,20,Career
```

不增加ID、数据库或单独的CSV版本列，不改当前路径 `iCloud Drive/Shortcuts/work_log.csv`。新文件可使用上面的五列表头；原文件无须重写表头或历史行，不在文件中间追加新表头。

## 需要用户在iPhone手动完成的操作

这些操作在读端开发通过后再执行，本轮无需改手机。

1. 在快捷指令App复制当前工时快捷指令，保留原版作为输入回退；确认现有CSV目标和原变量对应关系。不要把真实记录或含私人字段的快捷指令公开到仓库。
2. 添加「列表」（List）和「从列表中选取」（Choose from List），四个单选项为IELTS、Projects、Academic、Career，把选择结果存为Category。列表选项用这些固定英文值，避免显示名称与CSV枚举不一致。[Apple列表动作说明](https://support.apple.com/guide/shortcuts/use-list-actions-apd4dcacc115/ios)
3. 将原事项输入映射为Task：最小方案是「询问输入」（Ask for Input）的文本字段。保留有用的旧IELTS选择作为可选输入便利功能，不作为第一版必需的新分支。[Apple询问输入说明](https://support.apple.com/guide/shortcuts/use-the-ask-for-input-action-apd68b5c9161/ios)
4. 保留Actual Time、Effective Time变量和分钟单位；现有动作足够时不重复新增输入。确认非负数、Task非空、数字输出为不含千位分隔符的十进制分钟。沿用已验证的北京时间处理；若手机在其他时区，需要实际检查时间转换，不能直接把当地无时区文本当北京时间。
5. 修改组装CSV行的文本：顺序为时间、Task、Actual、Effective、Category。对Task做CSV转义（每个双引号变成两个双引号，再把整个Task包在双引号内），以支持逗号和换行；末尾追加一条记录分隔换行。具体文本替换动作需核对现有快捷指令后给出，不臆测变量名。
6. 保留原有写入/追加流程，先把副本目标改为测试文件，运行虚构输入并核对文件。上线批准后再改回原目标；若有桌面图标、Siri、组件或个人自动化绑定旧快捷指令，手动切换到新副本，避免一次触发同时写两次。

目前没有可导入的升级 `.shortcut` 文件，不能声称这些操作已经替用户完成。查看实际旧快捷指令后，可把上面的清单细化为逐动作、逐变量的操作说明。
