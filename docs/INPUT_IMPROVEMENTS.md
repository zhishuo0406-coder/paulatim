# 输入端与 Shortcuts 改进建议（2026-10-12）

基于当前源码和四列 CSV 契约制定。尚未收到实际快捷指令导出，因此没有核实手机动作、变量、追加文件方式，也没有修改 iPhone。本文是建议，不是新字段已经上线。

2026-10-12更新：用户新增长期兼容要求后，永久record_id和版本化迁移已成为基础设计要求；本表中关于新增字段的早期建议须结合 [长期数据审计与设计](DATA_COMPATIBILITY_AUDIT.md) 阅读，不能先改变生产CSV格式。

## 优先改输入体验，保留当前四列

| 字段 | 建议 | 目的与边界 |
| --- | --- | --- |
| timestamp | 普通记录自动填北京时间，新增“补记”入口，让用户选择记录归属日期和时间 | 日期决定日报归属。先明确当前时间代表完成时间还是开始时间，避免跨天记录误归属；不能直接把其他时区的本地时间写成北京时间 |
| task | 常用事项点选，保留“其他：手动输入”；同一事项固定名称 | 避免 Listening、听力、雅思听力被统计为三种事项。只规范新输入，不自动重写历史 |
| actual_minutes | 数字输入，提供 15、25、30、45、60 分钟及自定义 | 一律存分钟，允许小数；手机端拦截负数、空值。零分钟给提醒，不悄悄删记录 |
| effective_minutes | 明确为“实际时长中有效投入的分钟数”；数字输入，不自动猜测 | 通常应在 0 到实际分钟之间。超出时让用户修改或明确确认；读端仍保留原有警告规则 |

不要把“专注程度打分”“完成百分比”填进 effective_minutes；这两个概念与有效分钟不同。有效率由报告计算，不需要再增加输入字段。

常用 Task 可按你的实际活动设置，例如 Listening、Speaking、Writing、Reading、项目开发、论文阅读、求职准备。具体名单需根据实际使用调整。固定事项适合点选列表；输入时长适合数字输入。Apple 的 [列表动作说明](https://support.apple.com/guide/shortcuts/apd4dcacc115/ios) 和 [询问输入说明](https://support.apple.com/guide/shortcuts/apd68b5c9161/ios) 支持这两种动作；以下组合流程是本项目建议。

## 建议的第一版流程

1. 选“立即记录”或“补记”。普通记录自动取时间；补记选择归属时间。
2. 点选常用 Task；选“其他”才打开文本输入。去掉首尾空白并检查非空。
3. 选实际时长预设或数字自定义，再填有效分钟。遇到异常返回修改，不能在异常输入后继续自动追加。
4. 显示一行预览：日期时间、事项、实际分钟、有效分钟；提供保存、取消。检查失败或取消时不写文件。
5. 按原四列生成 CSV，正确转义 Task：先将每个双引号替换为两个双引号，再给整个 Task 加双引号。数字输出为使用小数点、不带千位分隔符的分钟数。
6. 沿用原追加文件动作，追加一次且只追加一条记录。文件不存在、写入失败时显示失败；仅写入动作成功后显示“已写入 iCloud 文件”。这不代表 Windows 已同步或邮件已收到。

第一次修改应复制原快捷指令，副本先写 `Shortcuts/work_log_input_test.csv`，用虚构事项验证中文、逗号、引号、小数、取消、连续追加、补记，再核对 Windows 读到的文件。不要把测试文件设为正式来源。快捷指令组件、Siri 与自动化入口只绑定一个版本，避免重复记录。

## 后续字段：先兼容读端，再改手机

| 字段 | 优先级 | 建议 |
| --- | --- | --- |
| Category | 基础数据架构之后 | 独立选择 IELTS / Projects / Academic / Career；新版契约待设计确认，不能现在直接追加正式CSV。旧四列缺失分类用null，不能默认IELTS |
| Project / 项目名称 | 有多个项目后再考虑 | Category=Projects 只回答大类，项目名称回答具体项目。先用固定 Task 命名观察需求，再决定是否新增字段 |
| Note / 备注 | 暂缓 | 有复盘需求时可选填一句成果或障碍；不要每次强制长文本。当前 CSV 不支持该列 |
| record_id | 基础必需 | 永久身份由登记或新输入一次生成，无需用户手填；重试复用，重复检测单独实现 |
| started_at / ended_at | 计时功能需要时再考虑 | 单独设计兼容与跨天规则，不能补造历史开始/结束时间 |
| 有效率、星期、日/周总计 | 无需输入 | 均由已有时间与分钟数计算，避免重复维护 |

分类实现与验收方案见 [SHORTCUTS_MIGRATION.md](SHORTCUTS_MIGRATION.md)。当前程序仍拒绝五列或混合四/五列 CSV。第一版四列体验优化和后续字段扩展应分别验收。

## 尚需实际快捷指令才能核对的内容

具体动作名称和顺序、每个变量绑定、时间格式/时区、数字格式、CSV转义、末尾换行、追加而非覆盖、保存失败的反馈，以及桌面组件/个人自动化是否重复触发。拿到 `.shortcut` 导出或编辑器完整步骤后，才能给出逐动作改法；目前没有可直接导入的升级文件。
